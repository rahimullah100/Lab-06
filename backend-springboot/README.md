# CompusHub UI

React and Vite frontend prototype for Enterprise Web Applications Lab 04.

## Included

- Bootstrap responsive layout and navigation bar
- React Router pages: Dashboard, Courses, Students, Sections, and Registrations
- Static Course Management form and two sample course records
- No backend or API connection, as required by the lab brief

## Run the project

```bash
npm install
npm run dev
```

Open the Vite address shown in the terminal, normally `http://localhost:5173`.

## Verify before submission

```bash
npm run build
npm run lint
```
